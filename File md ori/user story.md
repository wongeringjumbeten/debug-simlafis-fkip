 a.  Admin 
 User Story  Story Point 
 Sebagai  admin,  saya 
 ingin melakukan login. 
 Sehingga:  Admin  dapat 
 mengakses sistem 
 Title  : Login 
 Actor  : Admin 
 Scenario  : 
 ●  Admin membuka website 
 ●  Sistem menampilkan  homepage 
 ●  Admin klik “Login” 
 ●  Sistem menampilkan form login: 
 - email 
 - password 
 ●  Admin harus mengisi email dan password 
 ●  Sistem memvalidasi email dan password

 dashboard

 pesan kesalahan

 tersembunyi

 2.  Lupa Password 
 a.  Admin 
 User Story  Story Point 
 Sebagai  Admin  yang 
 lupa  kata  sandi,  saya 
 ingin  mengajukan 
 pemulihan  password  via 
 email. 
 Sehingga:  Saya  dapat 
 memperbarui  kata  sandi 
 dan  mengakses  kembali 
 akun saya. 
 Title  : Lupa Password / Reset Password 
 Actor  : Admin 
 Scenario  : 
 ●  Admin  mengklik  tautan  Lupa  Password  di 
 halaman  Login  . 
 ●  Sistem menampilkan  form  input email terdaftar. 
 ●  Admin  menginputkan  email  dan  mengklik  Kirim 
 Link Reset Password. 
 ●  Sistem memeriksa ketersediaan email: 
 ○  Jika  email  terdaftar,  sistem  mengirimkan 
 email berisi  link/token reset password  . 
 ○  Jika  email  tidak  ditemukan,  sistem 
 menampilkan pesan kesalahan. 
 ●  Admin  membuka  tautan  dari  email, 
 menginputkan  password  baru,  dan  menyimpan 
 perubahan.

 3.  Register 
 a.  Kalab 
 User Story  Story Point 
 Sebagai  Kalab,  saya 
 ingin  mendaftarkan  akun 
 baru ke dalam sistem. 
 Sehingga:  Saya  memiliki 
 akun  terverifikasi  untuk 
 melakukan  pengajuan 
 sewa alat dan ruangan. 
 Title  :  Title:  Registrasi Akun Kalab 
 Actor  : Kalab 
 Scenario  : 
 ●  Kalab membuka halaman  Register  . 
 ●  Sistem menampilkan  form  registrasi, berisi: 
 -  Nama Lengkap: Varchar (255 char) 
 -  Instansi / Organisasi: Varchar (255 char) 
 -  Kategori  Mahasiswa:  Enum 
 (‘Mahasiswa’,  ‘Internal-UNEJ’, 
 'Luar-UNEJ') 
 -  Nomor Telepon/WA: Varchar (20 char) 
 -  No Identitas: Varchar (100 char) 
 -  Email: Varchar (255 char) 
 -  Password: Varchar (255 char) 
 -  Konfirmasi Password: Varchar (255 char) 
 -  Foto Profil: Varchar (255 char) 
 -  Foto  Identitas  (KTM  atau  KTP):  Varchar 
 (255 char) 
 ●  Kalab mengisi seluruh data dan mengklik Daftar. 
 ●  Sistem memvalidasi data masukan: 
 ○  Jika  data  tidak  lengkap  atau  format  email 
 tidak  valid  atau  email  sudah  terdaftar 
 atau  konfirmasi  password  tidak  cocok, 
 sistem menampilkan pesan kesalahan. 
 ○  Jika  valid,  sistem  menyimpan  data  akun 
 baru. 
 ●  Sistem  mengarahkan  kalab  ke  halaman  Login 
 dengan notifikasi sukses.
